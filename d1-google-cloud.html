03一分鐘摘要

Token 就是成本
Token 是大型語言模型的計算與計費單位，Google 每月處理量已達千兆級。對 AI 新創來說，Token 用量直接反映在毛利上，必須當成核心成本管理。
三個管理方法
第一是分層選模型：規劃與複雜推理用最強的 Pro 級模型，大量執行降到 Flash 級，免費試用則用最輕量或開源模型。第二是讓 AI Agent 動態分配任務。第三是用平台的監控與限額功能，替個人與團隊設定上限，讓成本透明。
AI Agent 的四層架構
好的 Agent 需要推理、記憶、工具整合，以及確保可靠與合規的管控層。工具整合的意思，是把企業過去的微服務與資料變成 Agent 可以呼叫的技能。
今年的三個方向
Physical AI、自研前沿模型的 AI Labs，以及 AI Agent；其中 AI Agent 是今年最多獨角獸出現的領域。頂尖 AI 新創只領先同業 6–10 個月，賽道仍然開放。Google 也透過孵創計畫提供台灣新創最高 35 萬美元雲端抵免額。

04重點整理

  1. 模型要分層用：複雜推理用最強的，大量執行用便宜的。

    規劃用 Pro 級模型，執行降到 Flash 級，免費試用用最輕量或開源模型。

  2. 監控與限額，讓 Token 成本透明。

    平台都有用量監控，可以為個人與團隊設定上限。

  3. 好的 AI Agent 有四層。

    推理、記憶、工具整合（把過去的微服務與資料變成技能），以及讓 Agent 可靠、遵守規則的管控層。

  4. Physical AI 很熱，但機器人標準化還早。

    穿戴裝置、人形機器人都在發展；機器人觸覺等領域的資料與標準尚未建立。

05Takeaways

01建立 Token 用量監控與個人／團隊限額，每月檢視 AI 支出結構。
02訂出模型分層規則：哪些任務用高階模型、哪些一律用輕量或開源模型。
