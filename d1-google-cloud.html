Day 1 創業家日 / 生態系

Google Cloud：Token 成本與 AI Agent

10/14 上午 · 第 05 場KJ（慧榮） · Google Cloud

01講者 Snapshot

K
KJ（慧榮）
Google Cloud　大中華區新創技術副總

團隊過去兩年協助 5 家以上新創成為獨角獸。

02一分鐘摘要

這場在回答AI 新創怎麼管住 Token 成本？今年 AI 的主要方向是什麼？
核心論點Token 用量背後就是成本，要分層用模型、動態分配並監控；AI Agent 是今年最多獨角獸出現的領域，賽道仍開放。
  • Token 是 LLM 的計算與計費單位；Google 今年 5 月每月處理量已達千兆（10¹⁵）級。
  • Token 管理：分層選模型、AI Agent 動態路由、監控與限額。
  • 今年三大方向：Physical AI、自研前沿模型（AI Labs）、AI Agent。
  • 頂尖 AI 新創只領先同業 6–10 個月，人人都有機會。

03Key Takeaways

6–10 個月頂尖 AI 新創的領先幅度
5 家+兩年內協助成為獨角獸的新創
80%+融資流向 AI 相關的比例
  1. 模型要分層用：複雜推理用最強的，大量執行用便宜的。

    規劃用 Pro 級模型，執行降到 Flash 級，免費試用用最輕量或開源模型；有新創用前沿模型做簡單的 ls 指令，就是浪費。

  2. 監控與限額，讓 Token 成本透明。

    平台都有用量監控，可以為個人與團隊設定上限。員工大量用 AI 是好事，但帳單出來要知道錢花在哪。

  3. 好的 AI Agent 有四層。

    推理（選哪個模型）、記憶（短期與長期）、工具整合（把過去投資的微服務、資料變成 Agent 的技能）、管控層（讓 Agent 可靠、遵守規則，像數位同事）。

  4. Physical AI 很熱，但機器人標準化還早。

    穿戴裝置、人形機器人都在發展；例如機器人觸覺需要大量量化資料，標準還沒建立。

04對我們的意涵 CEO

建議思考建立公司內部的 Token 用量監控與模型分層規則。
