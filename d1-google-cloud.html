Google Cloud：Token 成本與 AI Agent

10/14 10:15吳貴融 KJ Wu · Google Cloud
AI
講者 Snapshot
吳
吳貴融 KJ Wu
Google Cloud　大中華區新創技術副總 · 官網介紹

負責 Google Cloud 新創技術團隊，協助新創制定雲端與雲端 AI 策略；曾帶領金融科技新創，並在大型顧問公司與雲端公司任職。 — 依 TSIC 官網講者介紹整理

01一分鐘摘要

這場在回答AI 新創怎麼管住 Token 成本？今年 AI 的主要方向是什麼？
核心論點Token 用量背後就是成本，要分層用模型、動態分配並監控；AI Agent 是今年最多獨角獸出現的領域，賽道仍開放。
  • Token 是 LLM 的計算與計費單位；Google 今年 5 月每月處理量已達千兆（10¹⁵）級。
  • Token 管理：分層選模型、AI Agent 動態路由、監控與限額。
  • 今年三大方向：Physical AI、自研前沿模型（AI Labs）、AI Agent。
  • 頂尖 AI 新創只領先同業 6–10 個月，人人都有機會。

02Key Takeaways

  1. 模型要分層用：複雜推理用最強的，大量執行用便宜的。

    規劃用 Pro 級模型，執行降到 Flash 級，免費試用用最輕量或開源模型。

  2. 監控與限額，讓 Token 成本透明。

    平台都有用量監控，可以為個人與團隊設定上限。

  3. 好的 AI Agent 有四層。

    推理、記憶、工具整合（把過去的微服務與資料變成技能），以及讓 Agent 可靠、遵守規則的管控層。

  4. Physical AI 很熱，但機器人標準化還早。

    穿戴裝置、人形機器人都在發展；機器人觸覺等領域的資料與標準尚未建立。

03反思與行動

01建立 Token 用量監控與個人／團隊限額，每月檢視 AI 支出結構。
02訂出模型分層規則：哪些任務用高階模型、哪些一律用輕量或開源模型。
關鍵數字
6–10 個月頂尖 AI 新創的領先幅度
5 家+兩年內協助成為獨角獸的新創
80%+融資流向 AI 相關的比例
